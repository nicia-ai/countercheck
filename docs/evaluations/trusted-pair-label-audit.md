# Local pair-label provenance audit, 2026-11-03

Status: read-only source inspection; no new labels, data copying, model calls or human adjudication. **No inspected local corpus establishes human-confirmed true-pair ground truth.** This is a scoped finding, not proof that no such labels exist elsewhere.

The requirement here is one incoming assertion and one identified candidate, an explicit contradiction/non-contradiction label for that pair, and recorded human confirmation of that label. A request-level admission outcome, an author principal stored in a fictional seed, or a model-validator agreement does not establish those three facts.

## Evidence locations

The adjacent benchmark README lines 15–20 states the 5–9 candidate request shape and synthetic origin. Direct JSON inspection found only `id`, `domain`, `category`, `truth`, `request` top-level fields, `contradicts`/`restates` truth keys, and no single-candidate request.

Nicia classifier cases begin with the explicit synthetic/future-human-review qualification and define aggregate truth around lines 119–127. The retrieval fixture README's “How it was made”, “Limits”, and typed “Validation” sections explain model authorship, model validators, repeated conversion and incomplete negatives. Mixed-batch README “The classifier labels” explains the `collidesWith` targets; the source comment defines the field as a named accepted record. The two explicit contradiction targets are the cloud-only and data-residency seed records. No labels were copied or changed by this audit.

The audit searched the local adjacent admission benchmark and the relevant Nicia classifier, mixed-batch, retrieval and classifier-unit-test sources. Git commit authorship or a checked-in comment is not treated as proof of a human annotation pass. Before claiming the human 500 / locked 200 release gate, a real adjudication artifact must identify the pair, the service-contract rubric, the judgment, reviewer provenance and disagreement handling. Existing native public labels and AI-authored fixtures remain separately qualified development evidence.

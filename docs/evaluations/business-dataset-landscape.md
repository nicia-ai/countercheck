# Business contradiction datasets: practical expansion

Checked 2026-11-04 against primary publisher/author sources and actual public-file metadata. This is preparation research, with no provider calls, credentials or local locked-data access. Native labels below remain distinct from human judgments under Countercheck's service contract.

**Prioritize FinDVer information extraction as the additional finance track, with all annotated evidence retained and explicit envelope exclusions.** Its negative claims are deliberately annotated to contradict their evidence, unlike generic false-news labels. Pair that finance track with MultiNLI government/telephone/slate for short-text language coverage. Report the complete-evidence length coverage separately. The requirements release was inspected and deferred after its label and grouping audit. No shortened evidence or invented clear negatives should repair the denominator.

The exact input URL is `https://raw.githubusercontent.com/yilunzhao/FinDVer/e8bb237def4ce555a606a45edba22666e31df248/data/testmini.json`. Report files use the same root followed by `financial_reports/REPORT_FILENAME`. The repository contains 600 report JSON files totaling 771,429,112 bytes; selective fetching avoids downloading the whole corpus. IE testmini references 99 reports. Both full manifests were inspected only for schema/count/group-overlap research, with no model outputs or case-level prompt optimization.

Example schema keys are `example_id`, `subset`, `split`, `statement`, `explanation`, `entailment_label`, `relevant_context`, `report`. `entailment_label` is boolean; `relevant_context` is an integer list. Reports contain `{url, report_type, context, html_tables}`; each context item has `{id, context, type}`. The [author's input helper](https://github.com/yilunzhao/FinDVer/blob/e8bb237def4ce555a606a45edba22666e31df248/utils/model_input_utils.py) uses **zero-based array positions** into `report.context`, preserving the paragraph string.

For a bounded pair, claim=`statement`; evidence=all indexed context items, in original report order, with paragraph IDs and verbatim table/paragraph strings. Preserve table headers, units and captions. Never send `explanation`—it contains the reasoning and answer. Missing/invalid indices or malformed selected-source data fail preparation instead of creating partial support. An over-budget complete evidence set excludes its whole report group with an explicit count. One inspected small report's three IE examples require 2,930 / 3,530 / 4,381 evidence bytes: all exceed the current 2,048-byte comparison limit. After the selective cached pass, exact IE coverage is **23 eligible pairs in 16 complete report groups: 10 entailed and 13 refuted**. The source has 250 IE pairs (125/125); the 2,048-byte complete-evidence/group rule excludes 227 pairs in 83 groups. This is 9.2% input coverage, with substantial source/length conditioning, not a representative financial population. All 99 required report files (123,301,087 bytes) are cached locally with source hashes; no full report text enters Git. One repeated annotation index list `[7,8,7]` is represented as the same unique source support `[7,8]`, with original indices and a duplicate-reference counter retained. Empty unreferenced report positions remain in place; empty referenced support is rejected.

The paper describes expert perturbations introducing errors directly opposed by annotated evidence and independent annotation/validation. This supports native `false→refuted`, `true→entailed` for complete evidence, not for arbitrary individual paragraphs. First phase should include **IE only**. Numerical reasoning is a separate research slice; knowledge-intensive examples explicitly involve outside financial knowledge/regulations and should not become closed-world core pairs. Native gold is not newly adjudicated service gold.

Keep `testmini` as its original published evaluation variant; if the canonical schema only accepts train/dev/test, record split=`test`, variant=`testmini-ie`, and the original split string. The authors describe testmini as development/validation and test as standard evaluation. At this revision, all-subset mini/test share 155 report filenames, although IE-only mini/test share none; one complete evidence-index set is shared across the broader subsets. Do not infer globally disjoint documents from split names. Group by report/issuer and normalized content when making local optimization partitions; freeze before any later test inference.

The [root license](https://github.com/yilunzhao/FinDVer/blob/e8bb237def4ce555a606a45edba22666e31df248/LICENSE) is MIT. No distinct CC or issuer-text redistribution license appears in the inspected tree. Keep full report text and derived text manifests in ignored local cache; archive IDs, source URLs/revision, report/data SHA, labels, coverage and predictions. Preserve the distinction between the repository's declared license and unverified underlying issuer-text terms. A reproducible selective downloader can rebuild local inputs without redistributing all report text.

## Safe adaptation of the alternatives

For MultiNLI, use hypothesis as claim and premise as evidence; retain native `contradiction`, `entailment`, `neutral` and all available annotator labels. Exclude `gold_label='-'`; never manufacture a contradiction label from neutral or split the premise. Report three-way native accuracy/macro-F1 separately from contradiction precision/recall and API clear-negative coverage. Genre/byte-filtered subsets are adapted development measurements, not the official full matched/mismatched test leaderboard. Freeze source/sentence duplicate groups before local tuning. Published data is widely used for pretraining, and the telephone slice is general conversation rather than workplace dialogue.

For requirements, actual public CSV reads verified `pure.csv`: 2,211 pairs, 20 Conflict / 2,191 Neutral, SHA `b66bd0eaf5f27ccf9d4b52d4bede1b1c5b2a7e0717185a3c4a30fdd6ae25af3d`; and `cdn.csv`: 10,626 pairs, 5,553 Conflict / 1,673 Duplicate / 3,400 Neutral, SHA `068d231bd60ea9a6b68a555488f02e5c7ff80cd54e5076a65788354deb246775`. Their direct file IDs are 56391938 and 56391920 at `https://ndownloader.figshare.com/files/ID`. The publication identifies mixed upstream families including proprietary-origin DOORS and public requirement sources; the deposited CC0 declaration is not proof of independent human adjudication or uniform original source permissions. Preserve this provenance distinction. Pair random splitting leaks repeated requirements; connected-component splitting is essential. PURE's very small positive set limits confidence and high-recall precision resolution. The subsequent [release audit](requirements-dataset-audit.md) found each file forms a single shared-requirement component, and CDN contains 252 byte-identical ordered pairs with disagreeing labels, including identical self-pairs labeled Conflict. These releases are deferred; no labels were silently repaired or scored as reliable gold.

DECODE's conversation-level non-contradiction is not automatically a gold label for every arbitrary turn pair. Speaker identity, pronouns and omitted context matter. An evidence-index adaptation must keep all necessary turns and document the changed task/coverage; do not compare its shortened score directly with full-dialogue published results. LegalBench binary entailment variants, document QA, sentiment datasets and generic non-entailment corpora similarly cannot supply contradiction negatives/positives by renaming their labels.

No source here establishes Countercheck's independent human 500 / locked 200 service-contract release gate. The immediately executable additions should broaden measured financial and business-adjacent coverage while retaining that limitation.

## Measured cohort follow-up

The [first-pass business results](../../eval/results/business-2026-11-04/README.md) include a conservative 23-pair finance cohort preserving every eligible whole report group and a separately preregistered 82-pair cohort retaining all complete individually supported pairs. The latter preserves report identities for grouping and contains all original 23 pairs unchanged; only 59 cases are additional. Its 32.8% source coverage is still conditional on the current 2 KB evidence limit. Models and thresholds stayed fixed, and the cohorts are not 105 independent examples.
